# Chess MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Play chess against Claude from a clean web UI hosted on the homelab NUC, with Stockfish available to Claude as an advisor and a chess.com-style post-game review.

**Architecture:** One Python package with two entry points. `chess-mcp server` is a long-running Starlette app that owns the game, engines, review, persistence, the web UI and a JSON API. `chess-mcp mcp` is a stdio MCP server (mcp SDK v2 `MCPServer`) that Claude Code runs anywhere; each tool is an HTTP call to the game server.

**Tech Stack:** Python 3.13, uv, python-chess 1.11, mcp 2.3 (`mcp.server.mcpserver.MCPServer`), Starlette 1.7, uvicorn 0.54 + websockets, httpx 0.28, pytest 9 + pytest-asyncio 1.4, chessground 9.2.1 (ES module from jsDelivr), Stockfish 19.

**Spec:** `docs/superpowers/specs/2026-10-11-chess-mcp-design.md`

## Global Constraints

- Python `>=3.13`; run everything through `uv` (`uv run pytest`, `uv run chess-mcp ...`).
- mcp SDK is **v2**: `from mcp.server.mcpserver import MCPServer`; `from mcp.server.mcpserver.exceptions import ToolError`. `mcp.server.fastmcp` no longer exists.
- Starlette 1.x: use `lifespan=`, not `on_startup`.
- Claude never receives the background eval. Engine output reaches Claude only through the `analyze` tool and, after the game, `get_review`.
- Every API request and WebSocket connection requires the token unless the server runs with `--no-auth`, which is refused unless the host is loopback. Static files (`/`, `/static/*`) are public; they contain no game data.
- Env vars: server `CHESS_HOST` (default `127.0.0.1`), `CHESS_PORT` (default `8765`), `CHESS_TOKEN`, `CHESS_DATA_DIR` (default `~/.local/share/chess-mcp`), `CHESS_PUBLIC_URL`, `CHESS_REVIEW_DEPTH` (18), `CHESS_EVAL_DEPTH` (14), `CHESS_ENGINE_THREADS` (2), `STOCKFISH_PATH`. MCP client `CHESS_SERVER_URL` (default `http://127.0.0.1:8765`), `CHESS_TOKEN`.
- Stockfish lookup order: `STOCKFISH_PATH`, then `PATH`, then `/usr/games/stockfish`.
- Win% formula: `50 + 50 * (2 / (1 + exp(-0.00368208 * cp)) - 1)`, cp clamped to ±1000; mate → 100 or 0.
- Move accuracy: `100` if after ≥ before, else `clamp(103.1668100711649 * exp(-0.04354415386753951 * (before - after)) - 3.166924740191411 + 1, 0, 100)`.
- Rating thresholds live in one dict, `THRESHOLDS`, in `review/classify.py`.
- The web UI has no build step and no client-side chess rules; legal destinations and review FENs come from the server.
- Commits end with the two attribution lines from the session (`Co-Authored-By: ...`, `Claude-Session: ...`).

## Review Focus

1. **Promotion from the browser.** Dragging a pawn to the last rank must ask for a piece and send `e7e8q`; a bare `e7e8` must be rejected with a readable error, not crash. Test in Task 2.
2. **Claude's move notation varies.** `O-O`, `0-0`, `Nf3+`, `Nf3!?`, `e2-e4` and `E2E4` should all be accepted when legal. Test in Task 2.
3. **Two browser tabs (phone and laptop) both try to move.** The second move gets `not_your_turn`; both tabs end in the same state. Test in Task 10.
4. **Game server restarts while Claude waits.** `wait_for_turn` keeps retrying until its timeout, then reports the server as unreachable with the URL to check. Test in Task 12.
5. **The game ends while Claude is thinking** (human resigns). Claude's `make_move` gets a clear "game is over" error, `wait_for_turn` reports `game_over` exactly once, and chat still works for coaching. Test in Task 2 and Task 11.

```python
import argparse


def main(argv: list[str] | None = None) -> None:
    parser = argparse.ArgumentParser(prog="chess-mcp", description="Play chess against Claude.")
    sub = parser.add_subparsers(dest="command", required=True, metavar="{server,mcp}")

    if args.command == "server":
        from chess_mcp.config import ServerConfig
        from chess_mcp.server.run import run_server

        run_server(ServerConfig.from_env(no_auth=args.no_auth))
    else:
        from chess_mcp.config import McpConfig
        from chess_mcp.mcp_client.server import run_mcp

        run_mcp(McpConfig.from_env())
```

```python
"""One game of chess between the human and Claude.

Owns the board, the chat log, the game status, and what Claude has already
seen. Knows nothing about HTTP, MCP or engines. Every mutation bumps
`version`, wakes `wait_for_change`, and calls each listener.
"""

from __future__ import annotations

import asyncio
import random
import re
import time
from dataclasses import asdict, dataclass
from datetime import datetime
from typing import Callable, Literal

import chess
import chess.pgn

Side = Literal["human", "claude"]
MAX_CHAT_CHARS = 2000
_UCI_LIKE = re.compile(r"^([a-h][1-8])-?([a-h][1-8])([qrbn])?$")


class GameError(Exception):
    """A rule or request error that is shown to the player as-is."""

    def __init__(self, code: str, message: str):
        super().__init__(message)
        self.code = code
        self.message = message


@dataclass
class ChatMessage:
    id: int
    sender: str  # "human" | "claude"
    text: str
    ts: float
    ply: int


def color_name(color: chess.Color) -> str:
    return "white" if color == chess.WHITE else "black"


def parse_color(text: str) -> chess.Color:
    if text == "white":
        return chess.WHITE
    if text == "black":
        return chess.BLACK
    if text == "random":
        return random.choice([chess.WHITE, chess.BLACK])
    raise GameError("bad_color", f"Colour must be white, black or random, not {text!r}.")


def new_game_id() -> str:
    return f"{datetime.now():%Y%m%d-%H%M%S}-{random.randrange(16**4):04x}"


def _other(side: Side) -> Side:
    return "claude" if side == "human" else "human"


class GameSession:
    def __init__(self, human_color: chess.Color = chess.WHITE, game_id: str | None = None):
        self.listeners: list[Callable[[], None]] = []
        self.version = 0
        self._changed = asyncio.Event()
        self.claude_seen_game_id: str | None = None
        self._reset(human_color, game_id)

    def _reset(self, human_color: chess.Color, game_id: str | None) -> None:
        self.game_id = game_id or new_game_id()
        self.started_at = time.time()
        self.ended_at: float | None = None
        self.human_color = human_color
        self.board = chess.Board()
        self.chat: list[ChatMessage] = []
        self.status = "active"
        self.result = "*"
        self.reason: str | None = None
        self.winner: str | None = None
        self.draw_offer: Side | None = None
        self.claude_chat_seen = 0
        self.claude_seen_game_over = False
        self.archived = False

    # ---- sides -------------------------------------------------------
    @property
    def claude_color(self) -> chess.Color:
        return not self.human_color

    def color_of(self, side: Side) -> chess.Color:
        return self.human_color if side == "human" else self.claude_color

    def side_to_move(self) -> Side:
        return "human" if self.board.turn == self.human_color else "claude"

    # ---- mutations ---------------------------------------------------
    def new_game(self, human_color: chess.Color, by: Side) -> None:
        if self.status == "active" and len(self.board.move_stack) >= 2:
            raise GameError("game_in_progress", "Finish or resign the current game first.")
        self._reset(human_color, None)
        if by == "claude":
            self.claude_seen_game_id = self.game_id
        self._notify()

    def play(self, move: str, by: Side) -> str:
        self._require_active()
        if self.side_to_move() != by:
            raise GameError("not_your_turn", f"It is {self.side_to_move()}'s turn, not {by}'s.")
        parsed = self._parse_move(move)
        san = self.board.san(parsed)
        self.board.push(parsed)
        if self.draw_offer == _other(by):
            self.draw_offer = None
        self._check_board_end()
        self._notify()
        return san

    def add_chat(self, sender: Side, text: str) -> ChatMessage:
        text = text.strip()
        if not text:
            raise GameError("empty_message", "Message is empty.")
        msg = ChatMessage(
            id=len(self.chat) + 1,
            sender=sender,
            text=text[:MAX_CHAT_CHARS],
            ts=time.time(),
            ply=len(self.board.move_stack),
        )
        self.chat.append(msg)
        self._notify()
        return msg

    def resign(self, by: Side) -> None:
        self._require_active()
        self._end("resigned", self.color_of(_other(by)), f"{color_name(self.color_of(by))} resigned")
        self._notify()

    def offer_draw(self, by: Side) -> None:
        self._require_active()
        if self.draw_offer == _other(by):
            self._end("draw_agreed", None, "draw agreed")
        else:
            self.draw_offer = by
        self._notify()

    def answer_draw(self, by: Side, accept: bool) -> None:
        self._require_active()
        if self.draw_offer != _other(by):
            raise GameError("no_draw_offer", "There is no draw offer to answer.")
        if accept:
            self._end("draw_agreed", None, "draw agreed")
        else:
            self.draw_offer = None
        self._notify()

    # ---- Claude's view -------------------------------------------------
    def claude_events(self) -> list[str]:
        events = []
        if self.claude_seen_game_id != self.game_id:
            events.append("new_game")
        if self.status != "active" and not self.claude_seen_game_over:
            events.append("game_over")
        if self.draw_offer == "human":
            events.append("draw_offer")
        if any(m.sender == "human" and m.id > self.claude_chat_seen for m in self.chat):
            events.append("message")
        if self.status == "active" and self.side_to_move() == "claude":
            events.append("your_move")
        return events

    def claude_view(self, mark_seen: bool) -> dict:
        your_turn = self.status == "active" and self.side_to_move() == "claude"
        new_messages = [m.text for m in self.chat if m.sender == "human" and m.id > self.claude_chat_seen]
        view = {
            "game_id": self.game_id,
            "you_play": color_name(self.claude_color),
            "status": self.status,
            "result": self.result,
            "reason": self.reason,
            "turn": color_name(self.board.turn),
            "your_turn": your_turn,
            "in_check": self.board.is_check(),
            "fen": self.board.fen(),
            "board": self.board_text(self.claude_color),
            "moves": self.movetext(),
            "last_move": self._last_san(),
            "legal_moves": [self.board.san(m) for m in self.board.legal_moves] if your_turn else [],
            "draw_offer": self.draw_offer,
            "new_messages": new_messages,
        }
        if mark_seen:
            changed = (
                self.claude_seen_game_id != self.game_id
                or bool(new_messages)
                or (self.status != "active" and not self.claude_seen_game_over)
            )
            self.claude_seen_game_id = self.game_id
            self.claude_chat_seen = max((m.id for m in self.chat), default=0)
            if self.status != "active":
                self.claude_seen_game_over = True
            if changed:
                self._notify()
        return view

    # ---- browser view --------------------------------------------------
    def browser_state(self) -> dict:
        dests: dict[str, list[str]] = {}
        if self.status == "active" and self.side_to_move() == "human":
            for mv in self.board.legal_moves:
                targets = dests.setdefault(chess.square_name(mv.from_square), [])
                to = chess.square_name(mv.to_square)
                if to not in targets:
                    targets.append(to)
        last = self.board.peek() if self.board.move_stack else None
        return {
            "game_id": self.game_id,
            "fen": self.board.fen(),
            "turn": color_name(self.board.turn),
            "human_color": color_name(self.human_color),
            "moves": self._replay(),
            "last_move": [chess.square_name(last.from_square), chess.square_name(last.to_square)] if last else None,
            "check": self.board.is_check(),
            "dests": dests,
            "status": self.status,
            "result": self.result,
            "reason": self.reason,
            "winner": self.winner,
            "draw_offer": self.draw_offer,
            "chat": [asdict(m) for m in self.chat],
        }

    # ---- waiting ---------------------------------------------------------
    async def wait_for_change(self, timeout: float) -> bool:
        event = self._changed
        try:
            await asyncio.wait_for(event.wait(), timeout)
            return True
        except TimeoutError:
            return False

    # ---- text helpers ------------------------------------------------------
    def board_text(self, perspective: chess.Color) -> str:
        ranks = range(7, -1, -1) if perspective == chess.WHITE else range(8)
        files = list(range(8)) if perspective == chess.WHITE else list(range(7, -1, -1))
        rows = []
        for rank in ranks:
            cells = []
            for file in files:
                piece = self.board.piece_at(chess.square(file, rank))
                cells.append(piece.symbol() if piece else ".")
            rows.append(f"{rank + 1} " + " ".join(cells))
        rows.append("  " + " ".join(chess.FILE_NAMES[f] for f in files))
        return "\n".join(rows)

    def movetext(self) -> str:
        if not self.board.move_stack:
            return ""
        return chess.Board().variation_san(self.board.move_stack)

    def pgn(self) -> str:
        game = chess.pgn.Game()
        headers = game.headers
        headers["Event"] = "Chess vs Claude"
        headers["Site"] = "chess-mcp"
        headers["Date"] = datetime.fromtimestamp(self.started_at).strftime("%Y.%m.%d")
        headers["White"] = "Human" if self.human_color == chess.WHITE else "Claude"
        headers["Black"] = "Claude" if self.human_color == chess.WHITE else "Human"
        headers["Result"] = self.result
        if self.reason:
            headers["Termination"] = self.reason
        nodes: list[chess.pgn.GameNode] = [game]
        node: chess.pgn.GameNode = game
        for mv in self.board.move_stack:
            node = node.add_variation(mv)
            nodes.append(node)
        for msg in self.chat:
            target = nodes[min(msg.ply, len(nodes) - 1)]
            speaker = "Human" if msg.sender == "human" else "Claude"
            target.comment = (target.comment + " " if target.comment else "") + f"{speaker}: {msg.text}"
        return str(game)

    # ---- persistence -------------------------------------------------------
    def to_record(self) -> dict:
        return {
            "game_id": self.game_id,
            "started_at": self.started_at,
            "ended_at": self.ended_at,
            "human_color": color_name(self.human_color),
            "moves": [m.uci() for m in self.board.move_stack],
            "chat": [asdict(m) for m in self.chat],
            "status": self.status,
            "result": self.result,
            "reason": self.reason,
            "winner": self.winner,
            "draw_offer": self.draw_offer,
            "claude_chat_seen": self.claude_chat_seen,
            "claude_seen_game_id": self.claude_seen_game_id,
            "claude_seen_game_over": self.claude_seen_game_over,
            "archived": self.archived,
        }

    @classmethod
    def from_record(cls, record: dict) -> GameSession:
        human = chess.WHITE if record["human_color"] == "white" else chess.BLACK
        session = cls(human_color=human, game_id=record["game_id"])
        for uci in record["moves"]:
            move = chess.Move.from_uci(uci)
            if move not in session.board.legal_moves:
                raise ValueError(f"illegal move {uci} in saved game")
            session.board.push(move)
        session.started_at = record["started_at"]
        session.ended_at = record["ended_at"]
        session.chat = [ChatMessage(**m) for m in record["chat"]]
        session.status = record["status"]
        session.result = record["result"]
        session.reason = record["reason"]
        session.winner = record["winner"]
        session.draw_offer = record["draw_offer"]
        session.claude_chat_seen = record["claude_chat_seen"]
        session.claude_seen_game_id = record["claude_seen_game_id"]
        session.claude_seen_game_over = record["claude_seen_game_over"]
        session.archived = record["archived"]
        return session

    # ---- internals -----------------------------------------------------------
    def _require_active(self) -> None:
        if self.status != "active":
            raise GameError("game_over", f"The game is over ({self.result}, {self.reason}).")

    def _parse_move(self, text: str) -> chess.Move:
        cleaned = text.strip().rstrip("+#!?")
        match = _UCI_LIKE.match(cleaned.lower())
        if match:
            move = chess.Move.from_uci("".join(g for g in match.groups() if g))
            if move in self.board.legal_moves:
                return move
        try:
            return self.board.parse_san(cleaned)
        except ValueError:
            pass
        sample = ", ".join(sorted(self.board.san(m) for m in self.board.legal_moves)[:12])
        raise GameError("illegal_move", f"{text.strip()!r} is not a legal move here. Legal moves include: {sample}.")

    def _check_board_end(self) -> None:
        outcome = self.board.outcome(claim_draw=True)
        if outcome is None:
            return
        status = outcome.termination.name.lower()
        self._end(status, outcome.winner, status.replace("_", " "))

    def _end(self, status: str, winner: chess.Color | None, reason: str) -> None:
        self.status = status
        self.winner = None if winner is None else color_name(winner)
        self.result = "1/2-1/2" if winner is None else ("1-0" if winner == chess.WHITE else "0-1")
        self.reason = reason
        self.ended_at = time.time()
        self.draw_offer = None

    def _last_san(self) -> str | None:
        if not self.board.move_stack:
            return None
        before = self.board.copy()
        last = before.pop()
        return before.san(last)

    def _replay(self) -> list[dict]:
        board = chess.Board()
        out = []
        for mv in self.board.move_stack:
            out.append({"san": board.san(mv), "uci": mv.uci()})
            board.push(mv)
        return out

    def _notify(self) -> None:
        self.version += 1
        old, self._changed = self._changed, asyncio.Event()
        old.set()
        for listener in list(self.listeners):
            listener()
```

```python
"""Files on disk: the current game, finished games, reviews and the token."""

from __future__ import annotations

import json
import os
import re
import secrets
from pathlib import Path

_GAME_ID = re.compile(r"^\d{8}-\d{6}-[0-9a-f]{4}$")


class Store:
    def __init__(self, data_dir: Path):
        self.data_dir = Path(data_dir)
        self.games_dir = self.data_dir / "games"
        self.games_dir.mkdir(parents=True, exist_ok=True)
        self._current = self.data_dir / "current.json"

    # ---- current game ----
    def load_current(self) -> dict | None:
        if not self._current.exists():
            return None
        try:
            data = json.loads(self._current.read_text(encoding="utf-8"))
            if not isinstance(data, dict):
                raise ValueError("not an object")
            return data
        except (OSError, ValueError):
            self.discard_current()
            return None

    def save_current(self, record: dict) -> None:
        self._write_json(self._current, record)

    def discard_current(self) -> None:
        if self._current.exists():
            self._current.replace(self.data_dir / "current.json.bad")

    # ---- finished games ----
    def archive(self, record: dict, pgn: str) -> None:
        game_id = record["game_id"]
        self._write_json(self.games_dir / f"{game_id}.json", record)
        (self.games_dir / f"{game_id}.pgn").write_text(pgn, encoding="utf-8")

    def list_games(self, limit: int = 20) -> list[dict]:
        files = sorted(
            (p for p in self.games_dir.glob("*.json") if _GAME_ID.match(p.stem)),
            key=lambda p: p.stem,
            reverse=True,
        )[:limit]
        out = []
        for path in files:
            try:
                rec = json.loads(path.read_text(encoding="utf-8"))
            except (OSError, ValueError):
                continue
            out.append(
                {
                    "game_id": rec["game_id"],
                    "started_at": rec.get("started_at"),
                    "ended_at": rec.get("ended_at"),
                    "human_color": rec.get("human_color"),
                    "result": rec.get("result"),
                    "winner": rec.get("winner"),
                    "reason": rec.get("reason"),
                    "opening": rec.get("opening"),
                    "moves": len(rec.get("moves", [])),
                    "reviewed": (self.games_dir / f"{rec['game_id']}.review.json").exists(),
                }
            )
        return out

    def load_game(self, game_id: str) -> dict | None:
        if not _GAME_ID.match(game_id):
            return None
        path = self.games_dir / f"{game_id}.json"
        if not path.exists():
            return None
        return json.loads(path.read_text(encoding="utf-8"))

    # ---- reviews ----
    def load_review(self, game_id: str) -> dict | None:
        if not _GAME_ID.match(game_id):
            return None
        path = self.games_dir / f"{game_id}.review.json"
        if not path.exists():
            return None
        try:
            return json.loads(path.read_text(encoding="utf-8"))
        except (OSError, ValueError):
            return None

    def save_review(self, game_id: str, data: dict) -> None:
        self._write_json(self.games_dir / f"{game_id}.review.json", data)

    # ---- token ----
    def token(self) -> str:
        path = self.data_dir / "token"
        if path.exists():
            value = path.read_text(encoding="utf-8").strip()
            if value:
                return value
        value = secrets.token_urlsafe(24)
        fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_TRUNC, 0o600)
        with os.fdopen(fd, "w", encoding="utf-8") as fh:
            fh.write(value + "\n")
        os.chmod(path, 0o600)
        return value

    # ---- helpers ----
    @staticmethod
    def _write_json(path: Path, data: dict) -> None:
        tmp = path.with_name(path.name + ".tmp")
        tmp.write_text(json.dumps(data, ensure_ascii=False, indent=1), encoding="utf-8")
        tmp.replace(path)
```

```python
"""Engine-neutral analysis types. Scores are always from White's point of view."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Protocol

import chess
import chess.engine


class EngineError(Exception):
    pass


@dataclass(frozen=True)
class Score:
    cp: int | None = None
    mate: int | None = None

    def text(self, pov: chess.Color = chess.WHITE) -> str:
        sign = 1 if pov == chess.WHITE else -1
        if self.mate is not None:
            return f"#{self.mate * sign}"
        return f"{(self.cp or 0) * sign / 100:+.2f}"

    @classmethod
    def from_pov(cls, pov: chess.engine.PovScore) -> Score:
        white = pov.white()
        if white.is_mate():
            return cls(mate=white.mate())
        return cls(cp=white.score())


@dataclass(frozen=True)
class Line:
    move: str
    pv: list[str]
    score: Score


@dataclass(frozen=True)
class Analysis:
    depth: int
    lines: list[Line]


@dataclass(frozen=True)
class Limit:
    depth: int | None = None
    time_s: float | None = None


class Engine(Protocol):
    name: str

    async def analyse(self, board: chess.Board, limit: Limit, multipv: int = 1) -> Analysis: ...

    async def close(self) -> None: ...
```

```python
"""Any UCI engine, driven through python-chess's async API."""

from __future__ import annotations

import asyncio
import contextlib

import chess
import chess.engine

from chess_mcp.engines.base import Analysis, EngineError, Limit, Line, Score

DEFAULT_DEPTH = 18


class UciEngine:
    def __init__(self, name: str, path: str, options: dict | None = None):
        self.name = name
        self.path = path
        self.options = options or {}
        self._engine: chess.engine.UciProtocol | None = None
        self._transport: asyncio.SubprocessTransport | None = None
        self._lock = asyncio.Lock()

    async def _start(self) -> None:
        self._transport, self._engine = await chess.engine.popen_uci(self.path)
        if self.options:
            await self._engine.configure(self.options)

    async def analyse(self, board: chess.Board, limit: Limit, multipv: int = 1) -> Analysis:
        depth = limit.depth if (limit.depth or limit.time_s) else DEFAULT_DEPTH
        engine_limit = chess.engine.Limit(depth=depth, time=limit.time_s)
        async with self._lock:
            for attempt in (1, 2):
                try:
                    if self._engine is None:
                        await self._start()
                    infos = await self._engine.analyse(board, engine_limit, multipv=multipv)
                    break
                except (chess.engine.EngineError, chess.engine.EngineTerminatedError, OSError) as exc:
                    self._engine = None
                    if attempt == 2:
                        raise EngineError(f"{self.name} failed: {exc}") from exc
        lines = [
            Line(move=info["pv"][0].uci(), pv=[m.uci() for m in info["pv"]], score=Score.from_pov(info["score"]))
            for info in infos
            if info.get("pv")
        ]
        return Analysis(depth=max((info.get("depth", 0) for info in infos), default=0), lines=lines)

    async def close(self) -> None:
        if self._engine is not None:
            with contextlib.suppress(Exception):
                await asyncio.wait_for(self._engine.quit(), 2)
            self._engine = None
```

```python
"""Where engines come from: Stockfish discovery plus an optional engines.toml."""

from __future__ import annotations

import os
import shutil
import tomllib
from dataclasses import dataclass, field
from pathlib import Path

from chess_mcp.engines.base import Engine, EngineError
from chess_mcp.engines.uci import UciEngine


def find_stockfish() -> str | None:
    env = os.environ.get("STOCKFISH_PATH")
    if env and os.access(env, os.X_OK):
        return env
    found = shutil.which("stockfish")
    if found:
        return found
    if os.access("/usr/games/stockfish", os.X_OK):
        return "/usr/games/stockfish"
    return None


@dataclass
class EngineSpec:
    name: str
    path: str
    options: dict = field(default_factory=dict)


class EngineRegistry:
    def __init__(self, specs: list[EngineSpec]):
        self._specs = {s.name: s for s in specs}
        self._engines: dict[str, Engine] = {}

    @classmethod
    def discover(cls, config_file: Path | None, threads: int = 2) -> EngineRegistry:
        specs: dict[str, EngineSpec] = {}
        stockfish = find_stockfish()
        if stockfish:
            specs["stockfish"] = EngineSpec("stockfish", stockfish, {"Threads": threads, "Hash": 128})
        if config_file is not None and Path(config_file).exists():
            data = tomllib.loads(Path(config_file).read_text(encoding="utf-8"))
            for name, entry in data.get("engines", {}).items():
                specs[name] = EngineSpec(name, str(entry["path"]), dict(entry.get("options", {})))
        return cls(list(specs.values()))

    @classmethod
    def with_engines(cls, engines: dict[str, Engine]) -> EngineRegistry:
        registry = cls([EngineSpec(name, "<in-process>", {}) for name in engines])
        registry._engines = dict(engines)
        return registry

    def names(self) -> list[str]:
        return list(self._specs)

    def _available(self, name: str) -> bool:
        if name in self._engines:
            return True
        spec = self._specs.get(name)
        return spec is not None and os.access(spec.path, os.X_OK)

    def has(self, name: str) -> bool:
        return self._available(name)

    def info(self) -> list[dict]:
        return [{"name": s.name, "path": s.path, "available": self._available(s.name)} for s in self._specs.values()]

    def get(self, name: str = "stockfish") -> Engine:
        if name in self._engines:
            return self._engines[name]
        spec = self._specs.get(name)
        if spec is None:
            known = ", ".join(self._specs) or "none"
            raise EngineError(f"Unknown engine {name!r}. Available: {known}. Stockfish is found via STOCKFISH_PATH or PATH.")
        if not os.access(spec.path, os.X_OK):
            raise EngineError(f"{name} not found at {spec.path}. Install it or set STOCKFISH_PATH.")
        engine = UciEngine(spec.name, spec.path, spec.options)
        self._engines[name] = engine
        return engine

    async def close_all(self) -> None:
        for engine in self._engines.values():
            await engine.close()
```

```python
"""Engine score → expected score (win %), Lichess's formula."""

from __future__ import annotations

import math

from chess_mcp.engines.base import Score


def win_pct_white(score: Score) -> float:
    if score.mate is not None:
        return 100.0 if score.mate > 0 else 0.0
    cp = max(-1000, min(1000, score.cp or 0))
    return 50 + 50 * (2 / (1 + math.exp(-0.00368208 * cp)) - 1)


def for_side(win_white: float, white: bool) -> float:
    return win_white if white else 100.0 - win_white
```

```python
"""Accuracy per move and per player, following Lichess's published method."""

from __future__ import annotations

import math
from statistics import pstdev


def move_accuracy(before: float, after: float) -> float:
    """Both arguments are win % from the mover's point of view."""
    if after >= before:
        return 100.0
    raw = 103.1668100711649 * math.exp(-0.04354415386753951 * (before - after)) - 3.166924740191411
    return max(0.0, min(100.0, raw + 1))


def _windows(values: list[float], size: int) -> list[list[float]]:
    sliding = [values] if len(values) <= size else [values[i : i + size] for i in range(len(values) - size + 1)]
    padding = [values[:size]] * max(0, min(size, len(values)) - 2)
    return padding + sliding


def _harmonic(values: list[float]) -> float:
    if any(v <= 0 for v in values):
        return 0.0
    return len(values) / sum(1 / v for v in values)


def game_accuracy(win_whites: list[float], accuracies: list[float]) -> tuple[float | None, float | None]:
    """Volatility-weighted mean averaged with the harmonic mean, per colour.

    `win_whites[i]` is White's win % in position i (0 = start); move i leads
    from position i to i + 1. White moves on even i.
    """
    moves = len(accuracies)
    if moves == 0:
        return (None, None)
    size = max(2, min(8, moves // 10))
    weights = [max(0.5, min(12.0, pstdev(w))) for w in _windows(win_whites, size)]
    result: list[float | None] = []
    for colour in (0, 1):
        pairs = [(accuracies[i], weights[i]) for i in range(moves) if i % 2 == colour]
        if not pairs:
            result.append(None)
            continue
        weighted = sum(a * w for a, w in pairs) / sum(w for _, w in pairs)
        harmonic = _harmonic([a for a, _ in pairs])
        result.append((weighted + harmonic) / 2)
    return (result[0], result[1])
```

```python
"""Static exchange evaluation, used to spot sacrifices for the Brilliant rating.

Pins are ignored; this is a heuristic, and Brilliant also requires the engine
to approve the move.
"""

from __future__ import annotations

import chess

VALUES = {
    chess.PAWN: 1,
    chess.KNIGHT: 3,
    chess.BISHOP: 3,
    chess.ROOK: 5,
    chess.QUEEN: 9,
    chess.KING: 100,
}


def see(board: chess.Board, square: chess.Square, by: chess.Color) -> int:
    """Material `by` wins by starting a capture sequence on `square` (≥ 0)."""
    b = board.copy(stack=False)
    target = b.piece_at(square)
    if target is None or target.color == by:
        return 0
    gains: list[int] = []
    side = by
    value_on_square = VALUES[target.piece_type]
    while True:
        attackers = list(b.attackers(side, square))
        if not attackers:
            break
        origin = min(attackers, key=lambda s: VALUES[b.piece_type_at(s)])
        piece = b.piece_at(origin)
        gains.append(value_on_square)
        value_on_square = VALUES[piece.piece_type]
        b.remove_piece_at(origin)
        b.set_piece_at(square, piece)
        side = not side
    score = 0
    for gain in reversed(gains):
        score = max(0, gain - score)
    return score


def material_given_up(board_before: chess.Board, move: chess.Move) -> int:
    """Pawns the opponent can win after `move`, minus what `move` itself won."""
    mover = board_before.turn
    if board_before.is_en_passant(move):
        captured = 1
    else:
        piece = board_before.piece_at(move.to_square)
        captured = VALUES[piece.piece_type] if piece else 0
    promotion_gain = VALUES[move.promotion] - 1 if move.promotion else 0
    after = board_before.copy(stack=False)
    after.push(move)
    exposed = [
        see(after, square, not mover)
        for square, piece in after.piece_map().items()
        if piece.color == mover and piece.piece_type != chess.KING
    ]
    return max(exposed, default=0) - captured - promotion_gain


def is_sacrifice(board_before: chess.Board, move: chess.Move, threshold: int = 2) -> bool:
    return material_given_up(board_before, move) >= threshold
```

```python
"""Opening theory from the Lichess chess-openings dataset (CC0)."""

from __future__ import annotations

import functools
from dataclasses import dataclass
from pathlib import Path

import chess

DATA_DIR = Path(__file__).resolve().parent.parent / "data" / "openings"
MAX_NAME_PLIES = 40


@dataclass(frozen=True)
class Book:
    positions: frozenset[str]
    names: dict[str, tuple[str, str]]


def position_key(board: chess.Board) -> str:
    return board.epd()


@functools.cache
def load_book() -> Book:
    positions: set[str] = set()
    names: dict[str, tuple[str, str]] = {}
    for path in sorted(DATA_DIR.glob("*.tsv")):
        for line in path.read_text(encoding="utf-8").splitlines()[1:]:
            eco, name, pgn = line.split("\t")
            board = chess.Board()
            for token in pgn.split():
                if "." in token:
                    continue
                board.push_san(token)
                positions.add(position_key(board))
            names[position_key(board)] = (eco, name)
    return Book(frozenset(positions), names)


def book_plies(moves_uci: list[str]) -> int:
    book = load_book()
    board = chess.Board()
    count = 0
    for uci in moves_uci:
        board.push_uci(uci)
        if position_key(board) not in book.positions:
            break
        count += 1
    return count


def opening_name(moves_uci: list[str]) -> str | None:
    book = load_book()
    board = chess.Board()
    found: tuple[str, str] | None = None
    for uci in moves_uci[:MAX_NAME_PLIES]:
```

```python
"""Chess.com-style move ratings. Pure: numbers in, rating out.

Win values are the mover's expected score in percent. The order of checks
matters: the first matching rule wins.
"""

from __future__ import annotations

from dataclasses import dataclass
from enum import StrEnum


class Rating(StrEnum):
    BOOK = "book"
    BRILLIANT = "brilliant"
    GREAT = "great"
    BEST = "best"
    EXCELLENT = "excellent"
    GOOD = "good"
    INACCURACY = "inaccuracy"
    MISTAKE = "mistake"
    MISS = "miss"
    BLUNDER = "blunder"


RATING_ORDER = list(Rating)

THRESHOLDS: dict[str, float] = {
    "excellent": 2.0,  # max loss
    "good": 5.0,
    "inaccuracy": 10.0,
    "mistake": 20.0,  # above this: blunder
    "brilliant_max_loss": 2.0,
    "brilliant_min_alternative": 30.0,  # the other option must not be losing
    "brilliant_min_after": 50.0,  # the mover must not be worse after the sacrifice
    "already_won": 97.0,  # no brilliant/great moves in completely won positions
    "great_min_gap": 15.0,  # best minus second-best
    "great_max_second": 50.0,  # the second-best move must leave the mover worse off
    "miss_min_chance": 65.0,  # what counts as a winning chance
    "miss_min_loss": 10.0,
}


@dataclass(frozen=True)
class MoveFacts:
    played_best: bool
    win_best: float
    win_played: float
    win_second: float | None
    legal_count: int
    is_book: bool
    is_sacrifice: bool
    prev_rating: Rating | None

    @property
    def loss(self) -> float:
        return 0.0 if self.played_best else max(0.0, self.win_best - self.win_played)


def classify(f: MoveFacts, t: dict[str, float] = THRESHOLDS) -> Rating:
    if f.is_book:
        return Rating.BOOK
    loss = f.loss
    not_already_won = f.win_best < t["already_won"]
    alternative = f.win_second if f.played_best else f.win_best

    if (
        f.is_sacrifice
        and loss <= t["brilliant_max_loss"]
        and f.legal_count > 1
        and alternative is not None
        and alternative >= t["brilliant_min_alternative"]
        and f.win_played >= t["brilliant_min_after"]
        and not_already_won
    ):
        return Rating.BRILLIANT

    if (
        f.played_best
        and f.legal_count > 1
        and f.win_second is not None
        and f.win_best - f.win_second >= t["great_min_gap"]
        and f.win_second < t["great_max_second"]
        and not_already_won
    ):
        return Rating.GREAT

    if f.played_best:
        return Rating.BEST

    if (
        f.prev_rating in (Rating.MISTAKE, Rating.BLUNDER)
        and f.win_best >= t["miss_min_chance"]
        and loss > t["miss_min_loss"]
    ):
        return Rating.MISS

    if loss <= t["excellent"]:
        return Rating.EXCELLENT
    if loss <= t["good"]:
        return Rating.GOOD
    if loss <= t["inaccuracy"]:
        return Rating.INACCURACY
    if loss <= t["mistake"]:
        return Rating.MISTAKE
    return Rating.BLUNDER
```

```python
"""Engine pass over a finished game, then pure rating and accuracy logic."""

from __future__ import annotations

from dataclasses import dataclass
from typing import Callable

import chess

from chess_mcp.engines.base import Engine, Limit, Score
from chess_mcp.review.accuracy import game_accuracy, move_accuracy
from chess_mcp.review.book import book_plies, opening_name
from chess_mcp.review.classify import RATING_ORDER, MoveFacts, Rating, classify
from chess_mcp.review.model import MoveReview, PlayerSummary, Review
from chess_mcp.review.sacrifice import is_sacrifice
from chess_mcp.review.winprob import for_side, win_pct_white

Progress = Callable[[int, int], None]


@dataclass
class PositionEval:
    win_white: float
    score: Score | None  # None for finished positions
    best_uci: str | None
    pv_uci: list[str]
    second_win_white: float | None
    legal_count: int


def _terminal(board: chess.Board) -> PositionEval:
    if board.is_checkmate():
        win = 0.0 if board.turn == chess.WHITE else 100.0
    else:
        win = 50.0
    return PositionEval(win, None, None, [], None, 0)


async def analyse_positions(moves_uci: list[str], engine: Engine, depth: int, progress: Progress | None = None) -> list[PositionEval]:
    board = chess.Board()
    total = len(moves_uci) + 1
    out: list[PositionEval] = []
    for i in range(total):
        if i > 0:
            board.push_uci(moves_uci[i - 1])
        if board.outcome() is not None:
            out.append(_terminal(board))
        else:
            legal = board.legal_moves.count()
            analysis = await engine.analyse(board, Limit(depth=depth), multipv=min(2, legal))
            top = analysis.lines[0]
            second = analysis.lines[1] if len(analysis.lines) > 1 else None
            out.append(
                PositionEval(
                    win_white=win_pct_white(top.score),
                    score=top.score,
                    best_uci=top.move,
                    pv_uci=list(top.pv),
                    second_win_white=win_pct_white(second.score) if second else None,
                    legal_count=legal,
                )
            )
        if progress:
            progress(i + 1, total)
    return out


def _eval_text(ev: PositionEval, board_after: chess.Board) -> str:
    if ev.score is not None:
        return ev.score.text()
    outcome = board_after.outcome()
    return outcome.result() if outcome else "½-½"


def build_review(record: dict, evals: list[PositionEval], depth: int) -> Review:
    moves = list(record["moves"])
    if len(evals) != len(moves) + 1:
        raise ValueError("need one evaluation per position")
    in_book = book_plies(moves)
    board = chess.Board()
    reviews: list[MoveReview] = []
    accuracies: list[float] = []
    prev_rating: Rating | None = None
    for i, uci in enumerate(moves):
        white = board.turn == chess.WHITE
        before, after = evals[i], evals[i + 1]
        move = chess.Move.from_uci(uci)
        san = board.san(move)
        best_move = chess.Move.from_uci(before.best_uci) if before.best_uci else None
        best_line = board.variation_san([chess.Move.from_uci(u) for u in before.pv_uci[:6]]) if before.pv_uci else ""
        facts = MoveFacts(
            played_best=before.best_uci == uci,
            win_best=for_side(before.win_white, white),
            win_played=for_side(after.win_white, white),
            win_second=for_side(before.second_win_white, white) if before.second_win_white is not None else None,
            legal_count=before.legal_count,
            is_book=i < in_book,
            is_sacrifice=is_sacrifice(board, move),
            prev_rating=prev_rating,
        )
        rating = classify(facts)
        accuracy = 100.0 if (facts.is_book or facts.played_best) else move_accuracy(facts.win_best, facts.win_played)
        best_san = board.san(best_move) if best_move else None
        board.push(move)
        reviews.append(
            MoveReview(
                ply=i + 1,
                color="white" if white else "black",
                san=san,
                uci=uci,
                fen=board.fen(),
                rating=rating.value,
                loss=round(facts.loss, 2),
                accuracy=round(accuracy, 1),
                eval_after=_eval_text(after, board),
                win_white_after=round(after.win_white, 2),
                best_uci=before.best_uci,
                best_san=best_san,
                best_line=best_line,
            )
        )
        accuracies.append(accuracy)
        prev_rating = rating

    win_series = [ev.win_white for ev in evals]
    white_acc, black_acc = game_accuracy(win_series, accuracies)
    human_white = record["human_color"] == "white"

    def summary(color: str, accuracy: float | None) -> PlayerSummary:
        is_human = (color == "white") == human_white
        counts = {r.value: 0 for r in RATING_ORDER}
        for m in reviews:
            if m.color == color:
                counts[m.rating] += 1
        return PlayerSummary(
            name="You" if is_human else "Claude",
            color=color,
            accuracy=round(accuracy, 1) if accuracy is not None else None,
            counts=counts,
        )

    return Review(
        game_id=record["game_id"],
        opening=opening_name(moves),
        result=record.get("result", "*"),
        reason=record.get("reason"),
        white=summary("white", white_acc),
        black=summary("black", black_acc),
        moves=reviews,
        eval_series=[round(w, 2) for w in win_series],
        depth=depth,
    )


async def review_game(record: dict, engine: Engine, depth: int, progress: Progress | None = None) -> Review:
    evals = await analyse_positions(list(record["moves"]), engine, depth, progress)
    return build_review(record, evals, depth)
```

```python
"""Short background evaluation for the UI's eval bar. Never shown to Claude."""

from __future__ import annotations

import asyncio
from typing import Callable

import chess

from chess_mcp.engines.base import EngineError, Limit
from chess_mcp.engines.registry import EngineRegistry
from chess_mcp.review.winprob import win_pct_white


class LiveEval:
    def __init__(self, engines: EngineRegistry, depth: int, on_update: Callable[[], None]):
        self.engines = engines
        self.depth = depth
        self.on_update = on_update
        self._fen: str | None = None
        self._result: dict | None = None
        self._tasks: set[asyncio.Task] = set()

    def schedule(self, board: chess.Board) -> None:
        fen = board.fen()
        if fen == self._fen:
            return
        self._fen = fen
        self._result = None
        if board.outcome(claim_draw=True) is not None or not self.engines.has("stockfish"):
            return
        task = asyncio.get_running_loop().create_task(self._run(board.copy()))
        self._tasks.add(task)
        task.add_done_callback(self._tasks.discard)

    async def _run(self, board: chess.Board) -> None:
        try:
            analysis = await self.engines.get("stockfish").analyse(board, Limit(depth=self.depth))
        except EngineError:
            return
        if not analysis.lines or board.fen() != self._fen:
            return
        score = analysis.lines[0].score
        self._result = {"fen": board.fen(), "text": score.text(), "win_white": round(win_pct_white(score), 1)}
        self.on_update()

    def current(self, fen: str) -> dict | None:
        if self._result and self._result["fen"] == fen:
            return self._result
        return None
```

```python
"""Runs each game's review once, shares it between callers, caches it on disk."""

from __future__ import annotations

import asyncio
from typing import Callable

from chess_mcp.core.game import GameError
from chess_mcp.core.store import Store
from chess_mcp.engines.registry import EngineRegistry
from chess_mcp.review.analyzer import review_game
from chess_mcp.review.model import Review


class ReviewService:
    def __init__(self, store: Store, engines: EngineRegistry, depth: int):
        self.store = store
        self.engines = engines
        self.depth = depth
        self.listeners: list[Callable[[str, int, int], None]] = []
        self._tasks: dict[str, asyncio.Task[Review]] = {}
        self._progress: dict[str, tuple[int, int]] = {}

    def start(self, game_id: str) -> asyncio.Future[Review]:
        if game_id in self._tasks:
            return self._tasks[game_id]
        cached = self.store.load_review(game_id)
        loop = asyncio.get_running_loop()
        if cached is not None:
            done: asyncio.Future[Review] = loop.create_future()
            done.set_result(Review.from_dict(cached))
            return done
        record = self.store.load_game(game_id)
        if record is None:
            raise GameError("unknown_game", f"No saved game with id {game_id!r}.")
        if not self.engines.has("stockfish"):
            raise GameError("no_engine", "Stockfish is not installed on the server, so games can't be reviewed.")
        task = loop.create_task(self._run(game_id, record))
        self._tasks[game_id] = task
        return task

    def progress(self, game_id: str) -> tuple[int, int] | None:
        return self._progress.get(game_id)

    async def _run(self, game_id: str, record: dict) -> Review:
        def report(done: int, total: int) -> None:
            self._progress[game_id] = (done, total)
            for listener in list(self.listeners):
                listener(game_id, done, total)

        try:
            review = await review_game(record, self.engines.get("stockfish"), self.depth, report)
            self.store.save_review(game_id, review.to_dict())
            return review
        finally:
            self._tasks.pop(game_id, None)
            self._progress.pop(game_id, None)
```

```python
"""Everything the server shares between the WebSocket, the API and background tasks."""

from __future__ import annotations

import asyncio
import contextlib
import logging
import time

from starlette.websockets import WebSocket

from chess_mcp.config import ServerConfig
from chess_mcp.core.game import GameSession
from chess_mcp.core.store import Store
from chess_mcp.engines.registry import EngineRegistry
from chess_mcp.review.book import opening_name
from chess_mcp.server.live_eval import LiveEval
from chess_mcp.server.reviews import ReviewService

log = logging.getLogger("chess_mcp")
PRESENCE_SECONDS = 60


def load_session(store: Store) -> GameSession:
    record = store.load_current()
    if record is not None:
        try:
            return GameSession.from_record(record)
        except (KeyError, TypeError, ValueError) as exc:
            log.warning("saved game is unreadable (%s); starting a new one", exc)
            store.discard_current()
    return GameSession()


class AppState:
    def __init__(self, config: ServerConfig, store: Store, engines: EngineRegistry):
        self.config = config
        self.store = store
        self.engines = engines
        self.token = None if config.no_auth else (config.token or store.token())
        self.session = load_session(store)
        self.session.listeners.append(self._on_session_change)
        self.sockets: set[WebSocket] = set()
        self.live = LiveEval(engines, config.eval_depth, self.schedule_broadcast)
        self.reviews = ReviewService(store, engines, config.review_depth)
        self._claude_waits = 0
        self._claude_last_seen = 0.0
        self._last_presence = False
        self._broadcast_pending = False

    # ---- session changes ----
    def _on_session_change(self) -> None:
        s = self.session
        if s.status != "active" and not s.archived:
            s.archived = True
            if s.board.move_stack:
                record = s.to_record()
                record["opening"] = opening_name(record["moves"])
                self.store.archive(record, s.pgn())
        self.store.save_current(s.to_record())
        self.live.schedule(s.board)
        self.schedule_broadcast()

    # ---- broadcasting ----
    def schedule_broadcast(self) -> None:
        if self._broadcast_pending:
            return
        self._broadcast_pending = True
        asyncio.get_running_loop().create_task(self._broadcast())

    async def _broadcast(self) -> None:
        self._broadcast_pending = False
        payload = self.browser_state()
        for ws in list(self.sockets):
            try:
                await ws.send_json(payload)
            except Exception:
                self.sockets.discard(ws)

    def browser_state(self) -> dict:
        state = self.session.browser_state()
        state["type"] = "state"
        state["claude_connected"] = self.claude_connected()
        state["eval"] = self.live.current(self.session.board.fen())
        return state

    # ---- Claude ----
    def claude_view(self, mark_seen: bool = True) -> dict:
        view = self.session.claude_view(mark_seen)
        view["ui_url"] = self.config.ui_url
        return view

    def claude_connected(self) -> bool:
        return self._claude_waits > 0 or time.monotonic() - self._claude_last_seen < PRESENCE_SECONDS

    def mark_claude_seen(self) -> None:
        self._claude_last_seen = time.monotonic()
        self.check_presence()

    def claude_wait_started(self) -> None:
        self._claude_waits += 1
        self.mark_claude_seen()

    def claude_wait_finished(self) -> None:
        self._claude_waits = max(0, self._claude_waits - 1)
        self._claude_last_seen = time.monotonic()

    def check_presence(self) -> None:
        now = self.claude_connected()
        if now != self._last_presence:
            self._last_presence = now
            with contextlib.suppress(RuntimeError):  # no running loop (e.g. at import)
                self.schedule_broadcast()
```

```python
"""The browser's WebSocket."""

from __future__ import annotations

import asyncio
import contextlib
import json

from starlette.websockets import WebSocket, WebSocketDisconnect

from chess_mcp.core.game import GameError, parse_color
from chess_mcp.engines.base import EngineError
from chess_mcp.server.auth import token_matches
from chess_mcp.server.state import AppState


async def websocket_endpoint(ws: WebSocket) -> None:
    state: AppState = ws.app.state.chess
    await ws.accept()
    if state.token is not None and not token_matches(ws.query_params.get("token"), state.token):
        await ws.close(code=4401)
        return
    state.sockets.add(ws)
    try:
        await ws.send_json(state.browser_state())
        while True:
            raw = await ws.receive_text()
            try:
                msg = json.loads(raw)
                if not isinstance(msg, dict):
                    raise ValueError
            except ValueError:
                await ws.send_json({"type": "error", "code": "bad_json", "message": "Messages must be JSON objects."})
                continue
            try:
                await handle_message(state, ws, msg)
            except GameError as exc:
                await ws.send_json({"type": "error", "code": exc.code, "message": exc.message})
    except WebSocketDisconnect:
        pass
    finally:
        state.sockets.discard(ws)


def _text(msg: dict, key: str) -> str:
    value = msg.get(key)
    if not isinstance(value, str):
        raise GameError("bad_message", f"Missing {key!r}.")
    return value


async def handle_message(state: AppState, ws: WebSocket, msg: dict) -> None:
    session = state.session
    kind = msg.get("type")
    if kind == "move":
        session.play(_text(msg, "move"), by="human")
    elif kind == "chat":
        session.add_chat("human", _text(msg, "text"))
    elif kind == "new_game":
        session.new_game(parse_color(str(msg.get("human_color", "white"))), by="human")
    elif kind == "resign":
        session.resign("human")
    elif kind == "offer_draw":
        session.offer_draw("human")
    elif kind == "answer_draw":
        session.answer_draw("human", bool(msg.get("accept")))
    elif kind == "list_games":
        await ws.send_json({"type": "games", "games": state.store.list_games(50)})
    elif kind == "open_review":
        asyncio.get_running_loop().create_task(send_review(state, ws, _text(msg, "game_id")))
    else:
        raise GameError("bad_message", f"Unknown message type {kind!r}.")


async def send_review(state: AppState, ws: WebSocket, game_id: str) -> None:
    """Stream progress, then the review, in order, to one socket."""
    queue: asyncio.Queue[dict] = asyncio.Queue()

    async def safe_send(payload: dict) -> None:
        with contextlib.suppress(Exception):
            await ws.send_json(payload)

    def on_progress(gid: str, done: int, total: int) -> None:
        if gid == game_id:
            queue.put_nowait({"type": "review_progress", "game_id": gid, "done": done, "total": total})

    state.reviews.listeners.append(on_progress)
    try:
        future = asyncio.shield(state.reviews.start(game_id))
        while not future.done():
            getter = asyncio.ensure_future(queue.get())
            await asyncio.wait({getter, future}, return_when=asyncio.FIRST_COMPLETED)
            if getter.done():
                await safe_send(getter.result())
            else:
                getter.cancel()
        while not queue.empty():
            await safe_send(queue.get_nowait())
        review = future.result()
        await safe_send({"type": "review", "review": review.to_dict()})
    except GameError as exc:
        await safe_send({"type": "error", "code": exc.code, "message": exc.message})
    except EngineError as exc:
        await safe_send({"type": "error", "code": "engine_failed", "message": str(exc)})
    finally:
        state.reviews.listeners.remove(on_progress)
```

```python
            await asyncio.sleep(PRESENCE_TICK)
            state.check_presence()

    ticker = asyncio.create_task(tick())
    state.live.schedule(state.session.board)
    try:
        yield
    finally:
        ticker.cancel()
        await state.engines.close_all()


def build_app(config: ServerConfig, engines: EngineRegistry | None = None) -> Starlette:
    from chess_mcp.server.api import API_ROUTES

    store = Store(config.data_dir)
    if engines is None:
        engines = EngineRegistry.discover(config.data_dir / "engines.toml", threads=config.engine_threads)
    state = AppState(config, store, engines)
    routes = [
        Route("/", index),
        *API_ROUTES,
        WebSocketRoute("/ws", websocket_endpoint),
        Mount("/static", StaticFiles(directory=WEB_DIR), name="static"),
    ]
    app = Starlette(routes=routes, lifespan=lifespan)
    app.state.chess = state
    return app
```

```python
"""JSON API used by the MCP client (Claude's side)."""

from __future__ import annotations

import asyncio
import functools
import json
import time
from typing import Awaitable, Callable

import chess
from starlette.requests import Request
from starlette.responses import JSONResponse, Response
from starlette.routing import Route

from chess_mcp.core.game import GameError, color_name, parse_color
from chess_mcp.engines.base import EngineError, Limit
from chess_mcp.review.model import KEY_RATINGS
from chess_mcp.server.auth import token_matches
from chess_mcp.server.state import AppState

STATUS = {
    "not_your_turn": 409,
    "game_in_progress": 409,
    "game_over": 409,
    "no_draw_offer": 409,
    "unknown_game": 404,
    "no_engine": 503,
    "engine_failed": 503,
}

Handler = Callable[[AppState, Request, dict], Awaitable[dict | Response]]


def _error(code: str, message: str, status: int | None = None) -> JSONResponse:
    return JSONResponse({"error": code, "message": message}, status_code=status or STATUS.get(code, 400))


def endpoint(fn: Handler):
    @functools.wraps(fn)
    async def wrapper(request: Request) -> Response:
        state: AppState = request.app.state.chess
        if state.token is not None:
            header = request.headers.get("authorization", "")
            if not (header.startswith("Bearer ") and token_matches(header[7:], state.token)):
                return _error("unauthorized", "Missing or wrong token.", 401)
        body: dict = {}
        if request.method == "POST":
            raw = await request.body()
            if raw:
                try:
                    body = json.loads(raw)
                except ValueError:
                    return _error("bad_json", "Body is not valid JSON.")
                if not isinstance(body, dict):
                    return _error("bad_json", "Body must be a JSON object.")
        try:
            result = await fn(state, request, body)
        except GameError as exc:
            return _error(exc.code, exc.message)
        except EngineError as exc:
            return _error("engine_failed", str(exc))
        return result if isinstance(result, Response) else JSONResponse(result)

    return wrapper


def _number(value, name: str, low: float, high: float, default: float | None) -> float | None:
    if value is None:
        return default
    try:
        number = float(value)
    except (TypeError, ValueError):
        raise GameError("bad_request", f"{name} must be a number.") from None
    return max(low, min(high, number))


@endpoint
async def get_game(state, request, body):
    state.mark_claude_seen()
    return state.claude_view(mark_seen=True)


@endpoint
async def wait(state, request, body):
    timeout = _number(request.query_params.get("timeout"), "timeout", 0, 55, 45)
    deadline = time.monotonic() + timeout
    state.claude_wait_started()
    try:
        while True:
            events = state.session.claude_events()
            if events:
                return {"event": events[0], "events": events, "game": state.claude_view(mark_seen=True)}
            remaining = deadline - time.monotonic()
            if remaining <= 0:
                return {"event": "still_waiting", "events": []}
            await state.session.wait_for_change(remaining)
    finally:
        state.claude_wait_finished()


@endpoint
async def move(state, request, body):
    text = body.get("move")
    if not isinstance(text, str) or not text.strip():
        raise GameError("bad_request", 'Send {"move": "e4"}.')
    san = state.session.play(text, by="claude")
    message = body.get("message")
    if isinstance(message, str) and message.strip():
        state.session.add_chat("claude", message)
    state.mark_claude_seen()
    return {"played": san, "game": state.claude_view(mark_seen=True)}


@endpoint
async def chat(state, request, body):
    text = body.get("text")
    if not isinstance(text, str):
        raise GameError("bad_request", 'Send {"text": "..."}.')
    state.session.add_chat("claude", text)
    state.mark_claude_seen()
    return {"ok": True}


@endpoint
async def new_game(state, request, body):
    claude = parse_color(str(body.get("claude_color", "black")))
    state.session.new_game(not claude, by="claude")
    return state.claude_view(mark_seen=True)


@endpoint
async def offer_draw(state, request, body):
    state.session.offer_draw("claude")
    return state.claude_view(mark_seen=True)


@endpoint
async def respond_draw(state, request, body):
    state.session.answer_draw("claude", bool(body.get("accept")))
    return state.claude_view(mark_seen=True)


@endpoint
async def resign(state, request, body):
    state.session.resign("claude")
    return state.claude_view(mark_seen=True)


@endpoint
async def engines(state, request, body):
    return {"engines": state.engines.info()}


@endpoint
async def analyze(state, request, body):
    name = str(body.get("engine") or "stockfish")
    depth = _number(body.get("depth"), "depth", 1, 30, None)
    time_s = _number(body.get("time_s"), "time_s", 0.1, 30, None)
    multipv = int(_number(body.get("multipv"), "multipv", 1, 5, 1))
    if depth is None and time_s is None:
        depth = 18
    board = state.session.board.copy()
    if board.outcome(claim_draw=True) is not None:
        raise GameError("game_over", "The game is over; there is nothing to analyse.")
    engine = state.engines.get(name)
    analysis = await engine.analyse(
        board,
        Limit(depth=int(depth) if depth else None, time_s=time_s),
        multipv=min(multipv, board.legal_moves.count()),
    )
    lines = []
    for line in analysis.lines:
        pv = [chess.Move.from_uci(u) for u in line.pv[:10]]
        lines.append({"move": board.san(pv[0]), "score": line.score.text(board.turn), "pv": board.variation_san(pv)})
    state.mark_claude_seen()
    return {"engine": name, "depth": analysis.depth, "side_to_move": color_name(board.turn), "lines": lines}


@endpoint
async def games(state, request, body):
    limit = int(_number(request.query_params.get("limit"), "limit", 1, 50, 10))
    return {"games": state.store.list_games(limit)}


def _review_payload(review: dict, detail: str) -> dict:
    if detail == "full":
        return review
    moves = [] if detail == "summary" else [m for m in review["moves"] if m["rating"] in KEY_RATINGS]
    return {**review, "moves": moves}


@endpoint
async def review(state, request, body):
    game_id = request.path_params["game_id"]
    if game_id == "current":
        if state.session.status == "active":
            raise GameError("game_in_progress", "The current game is still being played. Reviews are available once it ends.")
        game_id = state.session.game_id
    detail = request.query_params.get("detail", "key_moments")
    if detail not in ("summary", "key_moments", "full"):
        raise GameError("bad_request", "detail must be summary, key_moments or full.")
    wait_s = _number(request.query_params.get("wait"), "wait", 0, 300, 30)
    task = state.reviews.start(game_id)
    try:
        result = await asyncio.wait_for(asyncio.shield(task), timeout=wait_s)
    except TimeoutError:
        done, total = state.reviews.progress(game_id) or (0, 0)
        return JSONResponse({"status": "running", "done": done, "total": total}, status_code=202)
    return {"status": "done", "review": _review_payload(result.to_dict(), detail)}


API_ROUTES = [
    Route("/api/game", get_game, methods=["GET"]),
    Route("/api/wait", wait, methods=["GET"]),
    Route("/api/move", move, methods=["POST"]),
    Route("/api/chat", chat, methods=["POST"]),
    Route("/api/new_game", new_game, methods=["POST"]),
    Route("/api/draw/offer", offer_draw, methods=["POST"]),
    Route("/api/draw/respond", respond_draw, methods=["POST"]),
    Route("/api/resign", resign, methods=["POST"]),
    Route("/api/engines", engines, methods=["GET"]),
    Route("/api/analyze", analyze, methods=["POST"]),
    Route("/api/games", games, methods=["GET"]),
    Route("/api/review/{game_id}", review, methods=["GET"]),
]
```

```python
"""HTTP client for the game server's /api."""

from __future__ import annotations

import httpx


class ApiError(Exception):
    def __init__(self, code: str, message: str):
        super().__init__(message)
        self.code = code
        self.message = message


class ApiClient:
    def __init__(self, base_url: str, token: str | None, transport: httpx.AsyncBaseTransport | None = None):
        self.base_url = base_url.rstrip("/")
        headers = {"Authorization": f"Bearer {token}"} if token else {}
        self._http = httpx.AsyncClient(base_url=self.base_url, headers=headers, transport=transport, timeout=30)

    async def _request(self, method: str, path: str, *, json: dict | None = None, params: dict | None = None, timeout: float = 30) -> dict:
        try:
            response = await self._http.request(method, path, json=json, params=params, timeout=timeout)
        except httpx.TransportError as exc:
            raise ApiError(
                "unreachable",
                f"Can't reach the chess server at {self.base_url} ({exc.__class__.__name__}). "
                "Check that it is running and that CHESS_SERVER_URL is right.",
            ) from exc
        if response.status_code == 401:
            raise ApiError("unauthorized", "The chess server rejected the token. Check CHESS_TOKEN.")
        try:
            data = response.json()
        except ValueError:
            raise ApiError("bad_response", f"Unexpected response from the chess server (HTTP {response.status_code}).") from None
        if response.status_code >= 400:
            raise ApiError(data.get("error", "error"), data.get("message", "Request failed."))
        return data

    async def game(self) -> dict:
        return await self._request("GET", "/api/game")

    async def wait(self, timeout: float) -> dict:
        return await self._request("GET", "/api/wait", params={"timeout": timeout}, timeout=timeout + 15)

    async def move(self, move: str, message: str | None = None) -> dict:
        return await self._request("POST", "/api/move", json={"move": move, "message": message})

    async def chat(self, text: str) -> dict:
        return await self._request("POST", "/api/chat", json={"text": text})

    async def new_game(self, claude_color: str) -> dict:
        return await self._request("POST", "/api/new_game", json={"claude_color": claude_color})

    async def offer_draw(self) -> dict:
        return await self._request("POST", "/api/draw/offer")

    async def respond_draw(self, accept: bool) -> dict:
        return await self._request("POST", "/api/draw/respond", json={"accept": accept})

    async def resign(self) -> dict:
        return await self._request("POST", "/api/resign")

    async def engines(self) -> dict:
        return await self._request("GET", "/api/engines")

    async def analyze(self, engine: str, depth: int | None, time_s: float | None, multipv: int) -> dict:
        body = {"engine": engine, "depth": depth, "time_s": time_s, "multipv": multipv}
        return await self._request("POST", "/api/analyze", json=body, timeout=60)

    async def games(self, limit: int) -> dict:
        return await self._request("GET", "/api/games", params={"limit": limit})

    async def review(self, game_id: str, detail: str, wait: float) -> dict:
        params = {"detail": detail, "wait": wait}
        return await self._request("GET", f"/api/review/{game_id}", params=params, timeout=wait + 15)

    async def aclose(self) -> None:
        await self._http.aclose()
```

```python
"""Plain-text renderings of API responses, written for Claude to read."""

from __future__ import annotations


def format_view(v: dict, ui_link: str | None) -> str:
    lines = [f"Game {v['game_id']}. You play {v['you_play']}."]
    if v["status"] == "active":
        lines.append("It is YOUR move." if v["your_turn"] else f"Waiting for the human ({v['turn']}) to move.")
        if v["in_check"]:
            lines.append("The side to move is in check.")
    else:
        lines.append(f"Game over: {v['result']} ({v['reason']}).")
    if v["draw_offer"] == "human":
        lines.append("The human offers a draw. Answer with respond_to_draw(accept=true or false).")
    elif v["draw_offer"] == "claude":
        lines.append("Your draw offer is waiting for the human.")
    if v["last_move"]:
        lines.append(f"Last move: {v['last_move']}")
    lines.append(f"Moves: {v['moves'] or '(none yet)'}")
    if v["new_messages"]:
        lines.append("New messages from the human:")
        lines.extend(f"  > {m}" for m in v["new_messages"])
    lines += ["", "Board (your side at the bottom; uppercase = White):", v["board"], f"FEN: {v['fen']}"]
    if v["legal_moves"]:
        lines.append("Legal moves: " + " ".join(v["legal_moves"]))
    if ui_link:
        lines.append(f"Web UI for the human: {ui_link}")
    return "\n".join(lines)


def format_analysis(r: dict) -> str:
    head = f"{r['engine']} at depth {r['depth']} ({r['side_to_move']} to move; scores from {r['side_to_move']}'s side):"
    body = [f"  {i}. {line['move']}  {line['score']}  {line['pv']}" for i, line in enumerate(r["lines"], 1)]
    return "\n".join([head, *body])


def _move_label(m: dict) -> str:
    number = (m["ply"] + 1) // 2
    return f"{number}. {m['san']}" if m["color"] == "white" else f"{number}... {m['san']}"


def format_review(r: dict, detail: str) -> str:
    lines = [f"Review of game {r['game_id']}: {r['opening'] or 'unknown opening'}. Result {r['result']} ({r['reason']})."]
    for side in ("white", "black"):
        p = r[side]
        accuracy = f"{p['accuracy']:.1f}%" if p["accuracy"] is not None else "n/a"
        counts = ", ".join(f"{k} {v}" for k, v in p["counts"].items() if v)
        lines.append(f"{p['name']} ({side}): accuracy {accuracy}; {counts or 'no moves'}")
    if detail != "summary":
        lines.append("")
        lines.append("All moves:" if detail == "full" else "Key moments:")
        if not r["moves"]:
            lines.append("  (none)")
        for m in r["moves"]:
            best = ""
            if m["best_san"] and m["best_uci"] != m["uci"]:
                best = f"; best was {m['best_san']} ({m['best_line']})"
            lines.append(f"  {_move_label(m)} [{m['rating']}] eval after {m['eval_after']}{best}")
    return "\n".join(lines)


def format_games(games: list[dict]) -> str:
    if not games:
        return "No finished games yet."
    lines = ["Recent games (newest first):"]
    for g in games:
        lines.append(
            f"  {g['game_id']}: human played {g['human_color']}, result {g['result']} ({g['reason']}), "
            f"{g['moves']} plies, {g['opening'] or 'unknown opening'}{', reviewed' if g['reviewed'] else ''}"
        )
    return "\n".join(lines)
```

```python
"""The stdio MCP server Claude Code runs. Every tool calls the game server."""

from __future__ import annotations

import asyncio
import time

from mcp.server.mcpserver import MCPServer
from mcp.server.mcpserver.exceptions import ToolError

from chess_mcp.config import McpConfig
from chess_mcp.mcp_client.api_client import ApiClient, ApiError
from chess_mcp.mcp_client.format import format_analysis, format_games, format_review, format_view

INSTRUCTIONS = """\
You are playing chess against the user. They play in a web UI; you play through these tools.

How to play:
1. Call get_game. If the user hasn't opened the web UI yet, give them the link it shows.
2. Call wait_for_turn. It returns when it is your move, the user sends a message, offers a
   draw, or the game ends. If it says still_waiting, call it again straight away.
3. On your move, think about the position yourself. You may call analyze to consult an
   engine whenever you like, but the choice of move is yours. Then call make_move, usually
   with a short, friendly message.
4. Answer the user's messages with send_message, or in make_move's message. Keep it brief.
5. Keep looping until the game ends; don't stop waiting while a game is active unless the
   user asks. After the game, call get_review and talk the user through the key moments.
"""

TOOL_NAMES = [
    "get_game",
    "wait_for_turn",
    "make_move",
    "send_message",
    "analyze",
    "list_engines",
    "get_review",
    "list_games",
    "new_game",
    "offer_draw",
    "respond_to_draw",
    "resign",
]


class ChessTools:
    def __init__(self, client: ApiClient, token: str | None):
        self.client = client
        self.token = token

    def _link(self, view: dict) -> str | None:
        url = view.get("ui_url")
        if not url:
            return None
        return f"{url}/?token={self.token}" if self.token else f"{url}/"

    def _view(self, view: dict) -> str:
        return format_view(view, self._link(view))

    async def _call(self, coro):
        try:
            return await coro
        except ApiError as exc:
            raise ToolError(exc.message) from exc

    async def get_game(self) -> str:
        """Show the current game: board, moves, whose turn it is, new messages from the user, and the web UI link."""
        return self._view(await self._call(self.client.game()))

    async def wait_for_turn(self, timeout_s: int = 45) -> str:
        """Wait until it is your move, the user sends a message or offers a draw, or the game ends.

        Returns 'still_waiting' if nothing happened within timeout_s seconds (max 55); then call it again.
        """
        deadline = time.monotonic() + max(1, min(timeout_s, 55))
        last_error: ApiError | None = None
        while True:
            remaining = deadline - time.monotonic()
            if remaining <= 0:
                if last_error is not None:
                    raise ToolError(last_error.message)
                return "still_waiting: nothing has happened yet. Call wait_for_turn again."
            try:
                result = await self.client.wait(remaining)
                last_error = None
            except ApiError as exc:
                if exc.code != "unreachable":
                    raise ToolError(exc.message) from exc
                last_error = exc
                await asyncio.sleep(min(2.0, max(0.0, deadline - time.monotonic())))
                continue
            if result["event"] == "still_waiting":
                continue
            return f"events: {', '.join(result['events'])}\n\n" + self._view(result["game"])

    async def make_move(self, move: str, message: str | None = None) -> str:
        """Play your move in SAN (e.g. Nf3, O-O, exd5, e8=Q) or UCI (g1f3). Optionally include a short chat message for the user."""
        result = await self._call(self.client.move(move, message))
        return f"You played {result['played']}.\n\n" + self._view(result["game"])

    async def send_message(self, text: str) -> str:
        """Send a chat message to the user; it appears in the web UI."""
        await self._call(self.client.chat(text))
        return "Sent."

    async def analyze(self, engine: str = "stockfish", depth: int | None = None, time_s: float | None = None, multipv: int = 1) -> str:
        """Ask a chess engine about the current position. Returns its top lines with scores from the side to move's point of view.

        depth: search depth (1-30, default 18). time_s: seconds to think instead of a depth. multipv: number of lines (1-5).
        """
        return format_analysis(await self._call(self.client.analyze(engine, depth, time_s, multipv)))

    async def list_engines(self) -> str:
        """List the chess engines the server has and whether each one is available."""
        result = await self._call(self.client.engines())
        return "\n".join(f"{e['name']}: {'available' if e['available'] else 'missing'} ({e['path']})" for e in result["engines"])

    async def get_review(self, game: str = "current", detail: str = "key_moments") -> str:
        """Review a finished game: accuracy, a rating for each move (brilliant ... blunder) and the engine's best lines.

        game: 'current' for the game just finished, or a game id from list_games.
        detail: 'summary', 'key_moments' (brilliant, great, miss, mistake and blunder moves) or 'full'.
        The first review of a game takes a little while; this waits for it.
        """
        while True:
            result = await self._call(self.client.review(game, detail, wait=240))
            if result["status"] == "done":
                return format_review(result["review"], detail)

    async def list_games(self, limit: int = 10) -> str:
        """List recently finished games with their ids, results and openings."""
        return format_games((await self._call(self.client.games(limit)))["games"])

    async def new_game(self, claude_color: str = "black") -> str:
        """Start a new game. claude_color is the colour YOU play: white, black or random. Fails if a game is in progress."""
        return self._view(await self._call(self.client.new_game(claude_color)))

    async def offer_draw(self) -> str:
        """Offer the user a draw."""
        return self._view(await self._call(self.client.offer_draw()))

    async def respond_to_draw(self, accept: bool) -> str:
        """Accept or decline the user's draw offer."""
        return self._view(await self._call(self.client.respond_draw(accept)))

    async def resign(self) -> str:
        """Resign the current game."""
        return self._view(await self._call(self.client.resign()))


def build_mcp_server(tools: ChessTools) -> MCPServer:
    server = MCPServer("chess", instructions=INSTRUCTIONS)
    for name in TOOL_NAMES:
        server.add_tool(getattr(tools, name))
    return server


def run_mcp(config: McpConfig) -> None:
    client = ApiClient(config.server_url, config.token)
    build_mcp_server(ChessTools(client, config.token)).run()
```

```python
"""Start the game server with uvicorn."""

from __future__ import annotations

import logging
import sys

import uvicorn

from chess_mcp.config import ServerConfig, is_loopback
from chess_mcp.server.app import build_app


def run_server(config: ServerConfig) -> None:
    if config.no_auth and not is_loopback(config.host):
        raise SystemExit("--no-auth is only allowed when CHESS_HOST is a loopback address.")
    logging.basicConfig(level=logging.INFO, format="%(levelname)s %(name)s: %(message)s")
    app = build_app(config)
    token = app.state.chess.token
    link = f"{config.ui_url}/?token={token}" if token else f"{config.ui_url}/"
    print(f"chess-mcp: open {link}", file=sys.stderr, flush=True)
    uvicorn.run(app, host=config.host, port=config.port, log_level="info", ws="websockets")
```

```python
"""End-to-end check: running game server + real MCP server over stdio + a browser-like client.

Usage: uv run python scripts/smoke.py [server_url] [token]
Defaults: http://127.0.0.1:8765 and the local token file.
"""

from __future__ import annotations

import asyncio
import json
import sys

import websockets
from mcp.client import Client
from mcp.client.stdio import StdioServerParameters

from chess_mcp.config import McpConfig


async def call(client: Client, name: str, args: dict | None = None) -> str:
    result = await client.call_tool(name, args or {})
    text = result.content[0].text
    if result.is_error:
        raise SystemExit(f"{name} failed: {text}")
    return text


async def browser_move(url: str, token: str, move: str) -> dict:
    ws_url = url.replace("http", "ws", 1) + f"/ws?token={token}"
    async with websockets.connect(ws_url) as ws:
        json.loads(await ws.recv())
        await ws.send(json.dumps({"type": "move", "move": move}))
        return json.loads(await ws.recv())


async def main() -> None:
    cfg = McpConfig.from_env()
    url = sys.argv[1].rstrip("/") if len(sys.argv) > 1 else cfg.server_url
    token = sys.argv[2] if len(sys.argv) > 2 else cfg.token
    params = StdioServerParameters(
        command="uv",
        args=["run", "--quiet", "chess-mcp", "mcp"],
        env={"CHESS_SERVER_URL": url, "CHESS_TOKEN": token or ""},
    )
    async with Client(params) as client:
        tools = {t.name for t in (await client.list_tools()).tools}
        print("tools:", ", ".join(sorted(tools)))
        print(await call(client, "get_game"))
        state = await browser_move(url, token, "e2e4")
        print("browser played e4:", state.get("type"), state.get("code", ""))
        print(await call(client, "wait_for_turn", {"timeout_s": 10}))
        print(await call(client, "analyze", {"depth": 12, "multipv": 2}))
        print(await call(client, "make_move", {"move": "c5", "message": "Smoke test says hi."}))
        print(await call(client, "resign"))
        print(await call(client, "get_review", {"detail": "full"}))
    print("SMOKE OK")


if __name__ == "__main__":
    asyncio.run(main())
```

```bash
sudo -u chess git -C /opt/chess-mcp checkout -q "$REF"
sudo -u chess env HOME=/var/lib/chess-mcp UV_CACHE_DIR=/var/lib/chess-mcp/.cache/uv uv sync --frozen --no-dev --project /opt/chess-mcp -q

cp /opt/chess-mcp/deploy/chess.service /etc/systemd/system/chess.service
systemctl daemon-reload && systemctl enable --now chess.service

systemctl is-active chess.service
echo "token: $(cat /var/lib/chess-mcp/token)"
```
